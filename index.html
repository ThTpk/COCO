2Dto3D

จากภาพตัวละคร 2D สามมุม (หน้า / หลัง / ข้าง) เป็นโมเดล 3D ที่มี texture โครงกระดูก และอนิเมชันพร้อมใช้ใน three.js หรือเกม

เดินเล่น → บังคับตัวละครเดินและวิ่งไปในฉาก
WASD หรือปุ่มลูกศร · Shift วิ่ง
 ดูโมเดล → สลับ clip, โครงกระดูก, เส้นโครง, รูปทรงล้วน
123 สลับมุมมอง

ทำงานยังไง

  1. แยกตัวละครจากพื้นหลังด้วย GrabCut แล้ว align ทุกมุมให้สูงเท่ากัน
  2. ตัดกริด voxel ด้วย silhouette โดยปั้นหน้าตัดเป็นวงรี ไม่ใช่สี่เหลี่ยม
  3. marching cubes แล้วเกลาผิวด้วย Taubin smoothing
  4. คลี่ UV ด้วย xatlas แล้ว bake texture จากภาพต้นฉบับทั้งสามมุม
  5. ประเมินตำแหน่งข้อต่อจากรูปทรง ตั้งชื่อกระดูกตามแบบ Mixamo
  6. สร้าง armature อนิเมชัน และ export glTF ผ่าน Blender แบบ headless

รันเอง

  1. วางภาพ front back side ลงใน input/
  2. .venv\Scripts\python.exe -m src.cli --rig blender
  3. ได้ output/character_rigged.glb ขนาดราว 1.2 MB พร้อม texture และ 3 clip
